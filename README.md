# Anyma

Sistema de gestão para lojas desenvolvido pela Camacho Tecnologia.

## Primeiro núcleo

- painel gerencial e indicadores;
- PDV com carrinho, pagamentos e baixa de estoque em memória;
- produtos, estoque e alertas de reposição;
- clientes, caixa, financeiro e relatórios;
- equipe e perfis preparados para autenticação.

## Executar

```bash
npm install
npm run dev
```

## Validar

```bash
npm test
npm run build
```

Esta entrega usa dados demonstrativos no navegador. Não insira dados reais antes da implementação do banco, autenticação e isolamento entre lojas.
